Vad innebär samarbete med GitHub? Vad är pull requests, branches och merge?

En branch är en kopia av din main verision på GitHub i den branschen kan du göra ändringar utan att påverka koden som används, när du är klar kan du skapa en pull request vilket skickar din verision som kan bli checkad av resten av ditt team och om allt stämmer kan det bli mergat vilket uppdaterar huvudkoden till din verision för att skapa en ny main.
